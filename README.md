# Multi-Store Workforce & Shift Management System (SQL)

## Project Overview
This project addresses real-world workforce allocation challenges in multi-location retail and service environments. By building a relational database schema and running optimized SQL queries, this system identifies available cross-store personnel to resolve peak-hour staffing shortages and improve scheduling efficiency.

##  Key Features & Business Impact
* **Relational Database Design:** Structured relational schema modeling `Stores`, `Employees`, and `Daily Shifts` to track availability and capacity.
* **Cross-Store Allocation:** Engineered optimized SQL queries to query available staff across nearby locations, eliminating weekend coverage gaps.
* **Workforce Planning:** Reduced scheduling conflicts and improved labor distribution during peak operational hours.

##  Database Schema
The database consists of three main relational tables:
1. `Stores`: Stores location data and operational requirements.
2. `Employees`: Contains staff profiles, primary store assignments, and working hours.
3. `Daily Shifts`: Tracks shift schedules, attendance, and staffing gaps.

##  Tech Stack
* **Language/Database:** SQL (MySQL)
* **Domain:** HR Analytics, Workforce Planning, Operations
